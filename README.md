# WELCS — конкурентная разведка (октябрь 2026)

- `index.html` — отчёт «WELCS: пять конкурентов и пять решений»: обзор, пять решений с графиками, фактами, наблюдениями и подробными разделами, все объявления, профили компаний, снимки экранов.
- `img/` — снимки экранов для полного отчёта.
- `data/` — таблица всех объявлений со ссылками, лид-магниты, каналы трафика SimilarWeb.

## Публикация на GitHub Pages

1. Создать репозиторий и загрузить содержимое этой папки в корень (вместе с файлом `.nojekyll`).
2. Settings → Pages → Source: «Deploy from a branch», ветка `main`, папка `/ (root)`.
3. Через 1–2 минуты сайт откроется по адресу `https://<аккаунт>.github.io/<репозиторий>/`.

Страницы работают без сервера: всё оформление и интерактив встроены в HTML, внешние подключения — только шрифты Google Fonts.
